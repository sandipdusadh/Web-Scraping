# 🛒 Price Intelligence

A production-style web scraping and price tracking application built with Python.

## Overview

Price Intelligence collects product information from e-commerce websites, stores historical price data, and provides an interactive dashboard for analyzing products and price trends.

## Features

* Product data extraction
* Pagination handling
* Request retries
* Rate limiting
* Data validation
* Duplicate detection
* Historical price tracking
* SQLite database storage
* Interactive Streamlit dashboard
* Automated tests
* Structured logging

## Tech Stack

* Python
* Requests
* BeautifulSoup
* Pandas
* SQLAlchemy
* SQLite
* Plotly
* Streamlit
* Pytest
